# FleetSentinel

Connected-vehicle intelligence platform and copilot. One normalized telemetry pipeline for a 100,000-vehicle mixed ICE/EV fleet answers three questions:
where are we losing money (idling and fuel), what will break next (predictive maintenance), and who is driving riskily (driver safety). A guardrailed AI copilot turns the answers into approved, audited actions.

> Motorq is used only as an industry reference. This is an independent academic exercise with no affiliation to Motorq.

- Full design: [`spec.md`](spec.md) (v3). Decisions: [`docs/decisions.md`](docs/decisions.md), ADRs in [`docs/adr/`](docs/adr).
- Build plan and stream ownership: [`docs/streams/STREAMS.md`](docs/streams/STREAMS.md).
- All data is synthetic, generated by our own simulator. No real personal or vehicle-owner data is used.

## Quick start

Requirements: Docker (8 GB free RAM for the `infra` profile), Python 3.12 + [uv](https://docs.astral.sh/uv/).

```bash
uv sync --all-packages
python tools/fs.py bootstrap        # certs + infra containers + migrations + Kafka topics   (Windows-friendly; `make bootstrap` is equivalent)
python tools/fs.py migrate --to 5   # optional: baseline schema before the 0006 performance migration (for the SQL write-up)
uv run pytest                       # unit tests + coverage gate (>= 80%)
```

Dev-only credentials (demo realm password `Passw0rd!`, `postgres/postgres`, Vault token `root`) live in `deploy/compose/.env.example`. Never reuse them outside a local demo.

## Layout

| Path | Purpose |
|---|---|
| `contracts/` | Frozen interfaces: Protobuf events, Kafka topics, OpenAPI, OEM mapping DSL + samples, demo tenants |
| `libs/fscore/` | Shared core: VIN/DTC, Kafka-compatible hashing, mapping engine, algorithms, generated event code |
| `services/` | gateway, normalizer, processor, lake_sink, api, agent, batch |
| `simulator/` | OEM connectors, routes, faults, ground-truth oracle, seed generation |
| `ml/` | Features, training, evaluation, safety score, look-alike vectors |
| `db/migrations/` | Ordered SQL: 3NF core, RLS, Timescale, hash-chained audit, reference data, perf, grants |
| `deploy/` | Compose stack, Mosquitto mTLS config, Keycloak realm, Vault init, Dockerfile |
| `tools/` | `fs.py` CLI, cert / realm / protobuf generators |
